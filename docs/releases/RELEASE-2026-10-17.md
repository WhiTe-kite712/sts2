## 发布前需核对的既有文案与实现差异

这些项目只记录，保留当前中文与玩法，未为了通过格式化测试改效果。它们不属于已验证的完整卡牌结算覆盖范围。

| 卡牌 | 当前需要确认的差异 |
|---|---|
| 考试/Exam | 0豪意时，中文“低于10翻倍”与代码选择治疗分支的边界不同。 |
| “佳”豪/MagnificentHao | 中文描述立即获得1豪、下回合抽1；代码采用抽牌计数→豪意计数能力，没有这两个固定授予。 |
| 无限豪/InfiniteHao | 中文先伤害后扣6豪；代码先扣豪再伤害，并使用do/while使低于6豪时仍尝试首轮。 |
| 封“神”榜/GodList | 卡牌MaxHpCap为7，Power为8；卡牌末句遗漏动词/回复生命，实际Power同时处理上限及恢复。 |
| 节奏/Rhythm | 当前中文简写“回合内”，代码只在拥有者一方回合触发。 |
| 测不准原理/UncertaintyPrinciple | 代码要求实际成功消耗牌后才给能量/抽牌，中文未明确这项条件。 |

## 安装与输出

将ZIP里的CodeFarmer文件夹放入游戏mods，另行安装BaseLib 3.4.7或以上。版本沿用用户清单的v0.0.8；此次验证对应游戏0.111.0，清单最低版本0.107.0未单独验证。

发布目录只需保留CodeFarmer文件夹、ZIP、SHA256及可选调试符号。源项目保留源码、测试、动画编辑输入、当前100FPS HTML/GIF预览和生成溯源文档；旧草稿、联系表、废弃预览与编译缓存从运行资源/项目中清理。
