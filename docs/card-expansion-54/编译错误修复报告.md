# 编译错误修复报告（2026-10-05）

用户粘贴的错误集中在 `tests/CardExpansionRegression/ExpansionRules.cs`：CS0246、CS0103，无法解析 HaoState、HaoStateExtensions、HiddenStatePower、OpenHaoStatePower、HaoStatStatePower、SequenceHistoryExtensions、PressForward、Rhythm 等类型或名称。

这些类型已经存在于当前模组源码，相应 using 也齐全。测试项目原先通过 HintPath 直接引用磁盘上的 MySts2Mod.dll，仅检查 DLL 是否存在，没有声明对模组项目的构建依赖。日志显示测试先报错，模组之后才生成新 DLL；测试读取了未包含新增类型的旧程序集。新版 DLL 已能检出这些类型名称。

已将 CardExpansionRegression 和同样配置的 GeniusPowerRegression 默认引用改为 ProjectReference。MSBuild 会先构建当前模组，再获取其实际输出 DLL；对子项目传入 DeployToGame=false。显式指定 ModDll 的旧用法保留，路径不存在时给出明确错误。

项目引用还会传递 Godot.SourceGenerators 与 Sts2ModAnalyzers。它们要求 Godot 项目环境或模组本地化文件，在控制台测试项目中会产生 CS8785 和 STS002。现仅在两个 Harness 的 CoreCompile 前移除这两个专用分析器，保留普通 .NET 分析器。模组项目自身的生成器、分析器和本地化检查继续运行。卡牌和能力效果源码没有修改。
